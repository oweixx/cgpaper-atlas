# CG Paper Atlas 검토 기록

대상: 27,362편, 확정한 8개 venue, 검색·통계·지도, 수집 및 생성 파이프라인, GitHub Pages 배포. 전체 논문을 사람이 검증한 결과는 아닙니다.

## 반영한 개선

- **Country / region** 필터: 논문 당시 소속 국가로 검색하며 국제 공동연구·학회/저널 중복을 제거합니다. 국가·검색어·venue·기간·주제·인용 수·정렬을 URL로 복원합니다. 국가 자료 실패 시 선택을 유지하고 재시도합니다.
- **Unknown affiliation**: 국가가 전혀 없는 논문과 미연결 논문을 포함합니다. 1,836편이며, 일부 저자의 국가만 없는 논문을 모두 포함하는 조건은 아닙니다.
- **분야 분류 v3**: 제목·문맥을 고려한 초록 규칙·OpenAlex 의미 키워드를 결합했습니다. 27,106 DOI의 주제 자료를 확보했고, 미분류는 기존 5,765편(21.1%)에서 4,000편(14.6%)으로 줄었습니다. 커버리지 개선과 정확도 개선은 구분합니다.
- **Topic evidence**: 각 논문의 모든 분야·세부 분야, 근거 문구, 외부 키워드·출처 점수·분류 버전을 확인합니다. 필요한 때만 분할 파일을 불러오며 실패 시 재시도합니다. 외부 점수를 분류 정확도로 표시하지 않습니다.
- **일관된 통계와 내보내기**: 검색·분야·국가 통계가 같은 라벨을 사용합니다. 필터 CSV 및 전체 CSV/XLSX/JSONL에 분야·세부 분야·분류 버전을 포함합니다. 기존 소속 국가 CSV 열을 유지합니다.
- 소속 자료와 지도 도형을 각각 지연 로딩하고, 적은 논문 수의 그래프는 정수 눈금을 사용합니다.

## 분류 검증 결과와 한계

분류기 확정 후 별도로 선정한 64편에서 분야 단위 micro-F1은 **58.4% → 68.8%**, precision은 **77.6% → 81.5%**, recall은 **46.8% → 59.5%**였습니다. 개발자와 동일한 AI가 참고 라벨을 작성했으므로 독립 전문가 검증이나 전체 정확도 추정치가 아닙니다. 30개 세부 분야의 정확도도 별도로 검증하지 않았습니다. 이 표본의 남은 오분류·누락을 공개합니다. [방법·평가 상세](TOPIC_CLASSIFICATION.md), [원본 평가](../data/topic_validation.json).

## 다음 개발 우선순위

| 우선순위 | 확인한 근거 | 권장 작업과 완료 기준 |
|---|---|---|
| 1. 전문가 검증과 분류 보정 | 현재 검증은 AI 참고 라벨이며 복합 연구의 부차적 기여, 역사적 용어, 분석 대상과 방법의 혼동이 남습니다. | 분야·시대·venue별 독립 전문가 정답셋과 세부 분야 정답셋을 마련하고 별도 평가용 표본을 유지합니다. 검토자·근거·날짜가 남는 수정 절차를 추가합니다. |
| 2. 역사적 레코드 정제 | 패널, CAD 워크숍 보고서·서지 목록 등이 기존 제외 규칙을 통과한 사례가 발견됐습니다. | 출처·문헌 유형을 확인한 뒤 제외 근거와 집계 변화를 공개합니다. 제목 단어만으로 연구논문을 대량 삭제하지 않습니다. 이번에는 corpus membership을 유지했습니다. |
| 3. 최초 로딩과 검색 성능 | `papers.json`은 약 63.4 MiB이며 전체 초록을 함께 읽습니다. 분류 근거는 16개 파일로 분할했고 열 때만 요청합니다. | 목록용 경량 인덱스와 상세 초록을 분리하고, 제한된 모바일 네트워크에서 검색 가능 시점·전송량·메모리를 비교합니다. |
| 4. 자료 갱신 정책 | 기존 DOI 조회와 HTTP 응답을 재사용하며 자동 갱신 일정이 없습니다. | 명시적인 refresh 옵션, 실패 시 기존 snapshot 유지, 변경 보고서를 먼저 구현합니다. 이후 갱신 주기와 최신호 연결·인용 조회일을 점검합니다. |
| 5. 분석 화면 연결 | 검색 조건은 URL에 보존하지만 Research areas와 Global research의 분석 조건은 별도 상태입니다. | 분석 기간·venue·분야·국가·지표를 URL에 보존하고 국가별 논문 목록으로 연결합니다. 차트·표·CSV 선택 일치를 검증합니다. |
| 6. 브라우저 회귀 검사와 유지보수 | CI는 단위·데이터·JS 문법을 검사하고 브라우저 검사는 별도 실행합니다. 일부 UI 코드는 긴 한 줄입니다. | 브라우저 검사를 배포 전 CI에 연결하고 UI를 기능별로 정리합니다. 템플릿과 생성된 6개 HTML의 일치도 검사합니다. |

## 통계 해석과 확인 범위

- 소속 국가가 확인된 논문 **25,526편(93.3%)**, 국가/지역 코드 **92개**입니다. 국적이나 거주지가 아니며 기관 매칭·저자 식별 오류 가능성이 있습니다. 국가별 합계를 더하면 국제 공동연구 때문에 전체를 초과합니다.
- 학회/저널 합계도 중복 membership입니다. 선택 결과에서 논문은 한 번만 세며 학회 개최연도와 저널 출판연도를 구분합니다.
- 단위 테스트 **25개**, 전체 논문 라벨·근거 재계산, 출처 ledger·식별자·연도·국가·내보내기 일치 검사를 수행합니다. 소프트웨어 검증은 주제의 과학적 정확도를 보증하지 않습니다.
- 브라우저 검사는 국가 필터 조합·URL·CSV·초기화·빈 결과·자료 실패/재시도, 연구 분야·지도·모바일, 분류 근거 지연 로딩·재시도를 확인합니다. [실행 결과](browser-qa.json), [분류 근거 화면](preview-topic-evidence.png).

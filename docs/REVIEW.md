# CG Paper Atlas 검토 기록

검토 대상: 2026-11-12 snapshot의 27,362편, 8개 venue, 검색·통계·지도 화면, 수집/생성 파이프라인, Pages 배포 구성. 논문 전체의 주제·소속을 수작업으로 검증한 결과는 아닙니다.

## 이번에 반영한 내용

- Refine your search에 **Country / region** 추가. 소속 국가가 한 명 이상의 저자에게 기록되어 있으면 포함하며, 논문 식별자 단위로 중복을 제거합니다.
- **Unknown affiliation**은 국가가 전혀 기록되지 않은 논문과 소속 자료에 연결되지 않은 논문을 포함합니다. 현재 1,836편입니다. 일부 저자의 소속만 누락된 논문까지 모두 뜻하지는 않습니다.
- 국가와 기존 검색 조건을 조합하고 URL로 복원합니다. 기존에 빠져 있던 최소 인용 수와 정렬도 URL에 보존하며 Reset all에서 초기화합니다.
- 필터된 CSV에 `affiliation_country_codes`, `affiliation_countries`를 추가했습니다. 전체 XLSX/CSV/JSONL snapshot은 기존 형식을 유지합니다.
- 소속 데이터와 지도 도형을 별도로 불러오고 재사용합니다. 국가 데이터 실패 시 선택을 보존하고 재시도를 제공하며, 해당 국가의 결과를 확인할 수 있을 때까지 CSV 내보내기를 막습니다.
- 논문 수가 적은 막대그래프에서 Y축 숫자가 중복되던 문제를 정수 눈금으로 수정했습니다.

## 다음 개발 우선순위

| 우선순위 | 확인한 근거 | 권장 작업과 완료 기준 |
|---|---|---|
| 1. 연구 분야 분류 품질 | 현재 제목 키워드 규칙만 사용하며 **5,765편(21.1%)**이 `Other / Unclassified`입니다. `retarget`처럼 이미지·동작 연구에 공통으로 쓰이는 단어도 같은 규칙에 걸립니다. | 분야·시대·venue별 표본을 사람이 라벨링한 뒤 규칙 또는 분류 모델을 평가합니다. 분야별 precision/recall, 분류 근거·버전·확신도를 기록하고 불확실한 항목은 미분류로 유지합니다. 초록 활용 시 C&G의 낮은 초록 확보율(7.4%)에 따른 편향도 비교해야 합니다. |
| 2. 최초 로딩과 검색 성능 | `papers.json`은 **64,141,255 bytes(61.2 MiB)**이고 현재 전체 JSON 및 초록을 읽어야 검색할 수 있습니다. 압축 전 크기이며 실제 전송량과 같지는 않습니다. | 목록/필터용 소형 인덱스와 초록 상세 데이터를 분리하고, 초록 검색은 필요에 따라 분할 로딩 또는 별도 인덱스를 사용합니다. 모바일 제한 네트워크에서 검색 가능 시점·전송량·메모리를 전후 비교합니다. |
| 3. 자료 갱신 절차 | API 응답을 캐시하며 OpenAlex에서 조회 완료한 DOI는 다음 실행 때 생략합니다. 단순 재실행만으로 기존 논문의 인용 수·소속이 갱신되지는 않습니다. 자동 갱신 일정도 없습니다. | 명시적인 `--refresh`와 갱신 대상/기간 옵션, 실패 시 기존 snapshot 유지, 변경 수치 보고를 먼저 구현합니다. 이후 갱신 주기를 정하고 최신호 연결·출처별 누락·인용 수 조회일을 점검합니다. |
| 4. 분석 화면 연결과 재현성 | 검색 화면의 조건은 URL로 공유되지만 Research areas와 Global research의 분석 조건은 별도로 초기화됩니다. 국가 분석에서 해당 논문 목록으로 바로 이동하는 기능도 없습니다. | 분석 화면의 기간·venue·주제·국가·지표를 URL에 보존하고, 국가별 논문 목록으로 조건을 넘깁니다. 같은 URL을 다시 열었을 때 표·지도·CSV가 같은 선택을 사용하도록 검증합니다. |
| 5. 회귀 검증 자동화와 유지보수 | 현재 CI는 데이터/단위/JS 문법 검사를 수행합니다. 브라우저 검증은 별도 실행이며, JS·CSS·HTML 일부가 긴 한 줄로 작성되어 변경 검토가 어렵습니다. | 브라우저 검증을 배포 전 CI에 연결합니다. UI 코드는 기능 단위로 정리하고 템플릿과 생성된 6개 HTML의 일치 여부를 자동 확인합니다. |

## 통계 해석과 검증 범위

- 소속 국가가 확인된 논문은 **25,526편(93.3%)**, 국가/지역 코드는 **92개**입니다. 국적·거주지가 아니며, 기관 매칭과 저자 식별 오류 가능성이 남습니다. 국가별 논문 합계는 다국적 공동연구 때문에 전체 고유 논문 수보다 클 수 있습니다.
- 학회/저널 합계는 중복 membership입니다. 선택된 논문은 한 번만 세며, 연도는 선택된 venue 순서에 따른 학회 개최연도/저널 출판연도를 사용합니다.
- 단위 테스트 15개와 데이터 검증으로 고유 식별자, 개최연도, source ledger, affiliation 합계, 내보내기 일치를 확인했습니다.
- 브라우저 검증은 국가 필터 조합·URL 복원·CSV·초기화·미상 국가·자료 로딩 실패/재시도와 기존 연구 분야·지도·모바일 화면을 확인합니다. [실행 결과](browser-qa.json), [국가 필터 화면](preview-country.png), [모바일 필터](preview-country-mobile.png).
